# 工资任务

实时工资计时器第一版。

用浏览器打开 `index.html` 就能运行。页面会把年薪、每周工时、累计收入、本次计时时长和暂停状态保存在浏览器本地存储里。

## 当前功能

- 年薪和每周工时输入
- 实时累计收入估算
- 实时时薪和本次收入
- 暂停和继续
- 结束工作后把本次收入计入累计收入
- 电脑和手机自适应布局

## 部署

线上地址：https://gongzi-renwu-production.up.railway.app

本项目可以直接部署到支持 Node 的平台。

```bash
npm start
```

平台需要提供 `PORT` 环境变量；如果没有提供，默认使用 `3000`。
